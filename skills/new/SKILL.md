---
name: new
description: Create a new task folder with numbered placeholder files (1_requirements … 5_report) and make it the active task. First step of the task workflow.
argument-hint: <task-id> [repo-dir]
---

## Step 0 — Load config
Read `.claude/task-workflow.yml` if it exists. Defaults for missing keys:
`language` = language of the user's request · `tasks_dir` = `tasks` · `repos.default` = `.`

Write all messages and generated files in `language`.

## Validate
Split `$ARGUMENTS` into `$ID` (first word) and `$REPO` (second word, default `repos.default`).

- `$ID` empty → stop: "Missing task ID. Usage: `/task:new <task-id> [repo-dir]`"
- Directory `$REPO` does not exist → stop: "Repo `$REPO` not found. repo-dir is relative to the workspace root." If `repos.list` is set, show it as the valid choices.
- `<tasks_dir>/$ID/` already exists → stop: "`<tasks_dir>/$ID/` already exists. Run `/task:spec` to continue."

## Create files (Write tool directly, no sub-agent)
Let `$T` = `<tasks_dir>/$ID`. Headings below are in English; translate them to `language`.

**`$T/1_requirements.md`**
```
# $ID — Requirements

<!-- task:placeholder — paste the raw requirement here, then delete this line -->
```

**`$T/2_spec.md`**, **`$T/3_plan.md`**, **`$T/4_review.md`**, **`$T/5_report.md`** — same shape:
```
# $ID — <Spec | Plan | Review | Report>

<!-- task:placeholder — generated by /task:<spec | plan | review | report> -->
```

**`$T/.repo`** — one line: `$REPO`

**`$T/assets/.gitkeep`** — empty

## Set active task
Write `$ID` to `<tasks_dir>/.current` (overwrite).

## Report
```
✅ Created $T/ (repo: $REPO)
👉 Next: fill in $T/1_requirements.md, then run /task:spec
```
